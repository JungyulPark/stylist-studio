# The Edit — 주간 트렌드 에디트 운영법

주소: `/edit`, `/edit/{slug}` (영어) · `/ko/edit`, `/ko/edit/{slug}` (한국어)

## 어떻게 발행되나

- 원고는 `functions/lib/edit-data.ts`의 `EDITIONS` 배열에 있다. 각 에디션의 `date`(월요일, UTC)가 되면
  자동으로 공개된다. 그 전에는 404이고 허브·이전/다음 글·사이트맵 어디에도 나오지 않는다.
- 공개되면 매시 크론이 저널 구독자(`journal_subscribers`)에게 그 호를 메일로 보낸다.
  발송 장부는 `ops_events`의 `journal.sent`(ref_id = slug)이고, 한 사람에게 한 호는 한 번만 간다.
  발행 후 6일이 지난 호는 보내지 않으므로, 준비된 원고가 떨어지면 메일은 조용히 멈춘다.
- 현재 준비된 원고: No. 01 (2026-11-09) ~ No. 08 (2026-12-28). **12월 말 전에 다음 원고를 추가해야 한다.**

## 새 에디션 추가 (약 15분)

1. `EDITIONS` 끝에 항목 추가: `no`는 +1, `date`는 직전 호 + 7일(월요일), `slug`는 영문 소문자와 하이픈.
   영어·한국어 모두 `title`, `dek`(160자 이내), `trend` 2문단, `wear` 3개, `pieces` 4개 이상, `skip`.
2. 이미지 2장 생성: `docs/MODEL_PROMPTS.md`의 브랜드 모델 레퍼런스로 여자·남자 각 1장 (4:5, 크림 스튜디오).
3. `scripts/fetch-assets.mjs`의 `EDIT`에 `'slug': ['여자 컷 id', '남자 컷 id']`를 넣고 스크립트를 실행하면
   `public/gallery/edit/{slug}-her.webp`, `-him.webp`가 만들어진다.
4. `npm test` — 월요일 간격, 중복 slug, 문구 규칙, 이미지 파일 존재를 테스트가 확인한다.

## 편집 규칙 (테스트가 강제)

- 실제 브랜드·디자이너·매체 이름 금지. 트렌드는 실루엣·색·소재로만 말한다.
- 이모지 금지, 퍼센트 수치 금지 (확인할 수 없는 주장은 쓰지 않는다).
- 구조는 항상 같다: 지금 일어나는 일 → 이렇게 입으세요(3) → 팔레트 → 핵심 아이템 → 피할 것.
